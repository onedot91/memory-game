# 게임 에셋 출처

## 직접 작성한 에셋

`src/game/art.ts`의 픽셀 행렬과 Canvas 명령으로 캐릭터, 적, 보스, 무기, 유물, 타일을 렌더링한다. 외부 그림 파일, 생성 이미지, 이모지 캐릭터는 게임 아트로 사용하지 않는다. 기존 학습 데이터의 문구는 원문을 유지한다.

논리 화면은 640×360. 테마별 팔레트와 네 가지 방 배치가 같은 파일에 있으며 캐릭터 방향·행동 프레임을 정의한다. `scene.ts`가 Phaser 텍스처와 애니메이션으로 등록한다.

`src/game/sound.ts`의 Web Audio 발진기와 envelope로 음향을 합성한다. 외부 음악·효과음 녹음 파일은 사용하지 않는다.

## 라이브러리

- Phaser 4.2.1: 설치된 패키지의 `LICENSE.md` 및 `package.json` 참고.
- lucide-react: 기존 프로젝트 의존성을 UI 아이콘에 재사용.

게임 코드에는 구매 또는 별도 다운로드한 에셋이 없다. 이미지 생성 금지 지시 이후 생성 도구를 사용하지 않았다. 이전 생성 원화는 런타임에서 제외했으며 빌드에 포함되지 않는다.
