# 암기 던전 구현 기록

## 최종 반영한 사용자 지시

- 이미지 생성 도구 없이 직접 저작한 픽셀 패턴과 CSS 사용.
- 긴 소개·설명 문구를 제거하고 선택·입력·피드백 중심으로 구성.
- PC에서 세로 스크롤 없이 준비, 전투, 결과, 설정, 도감, 기록 표시.
- 기본 암기와 던전의 데이터, 항목 번호, 정답·별칭 판정과 순서를 통일.
- 기본 암기의 사용자 지정 순서를 던전 시작 시 읽어 동일하게 적용.
- 카테고리 한 번 풀이를 원정 한 번으로 처리. 4·5·6·8·100개 원본 문항 수 유지.
- 던전의 반복 출제 제거. 문항 수에 맞춰 최대 6구간에 학습을 배분.
- 두 모드의 PC 문제 목록을 8칸 페이지로 표시. 모바일 기본 암기는 기존 목록 유지.
- 첫 오답 재입력, 두 번째 오답 정답 공개 후 자동 진행. 강화는 선택 사항이며 Enter로 계속 풀면 첫 선택지를 적용.
- 회복에 필요한 풀이도 남은 원래 문항을 사용. 추가 문항을 강제하지 않음.
- 공격 효과음은 짧은 sine 단음으로 변경. 기본 효과음 20%, 중첩 방지, 음소거 지원.

## 구현

- App.tsx: 두 모드 진입 및 unmount 전환.
- ClassicStudy.tsx: 기존 학습, 저장 키 유지. PC 페이지, IME/Enter 보호, 사용 지표.
- game/engine.ts, content.ts, types.ts: 세 던전, 여섯 무기, 열두 유물, 채점·전투·해금·복습 기록.
- game/DungeonGame.tsx, DungeonStudy.tsx, game.css: 학습·메뉴·HUD·한 화면 배치.
- game/Arena.tsx, scene.ts, art.ts, sound.ts: Phaser 4.2.1 렌더러, 원본 픽셀 아트·합성 음향.
- game/storage.ts, useActivity.ts: 로컬 저장, 기존 던전 기록 정리, JSON/CSV 내보내기, 활성 시간 측정.

## 검증

- `npm run lint`, `npm run build` 통과.
- 임시 tsx 드라이버: 180개 던전/무기/카테고리/정오답 조합 완주 + 90개 Enter 전용 흐름. 총 15,467개 검사, 554개 정답·별칭 포함.
- 문항 추가·중복 없음, 첫 오답 무피해, 제출 순번 중복 방지, 완료 보상 중복 방지, 기존 진행 복원, 선택한 문항의 오답 횟수 유지, 사용자 지정 순서 확인.
- 효과음 드라이버: 단일 sine 파형, 100ms 이내 종료, gain 상한, 연타 억제, 음소거·정지 확인.
- 실제 Codex 브라우저: 기본 암기 마지막 페이지, 세 던전의 6·100·4문항 완주, 두 번째 오답 자동 진행, 강화 없이 Enter 진행, 도감 페이지, 설정, 새로고침 이어하기 확인.
- 실제 CSS viewport 1280×720, 1440×900, 1920×1080에서 document 높이와 viewport 높이 일치. 1075×605에서도 8칸 던전 입력과 도감·결과가 화면 안에 표시.
- 일반 전투와 100문항 연속 진행에서 표시된 FPS 약 60, 새 콘솔 오류 없음. macOS, Codex 내장 브라우저 사용.

## 아직 수행하지 않은 출시 검증

- 네이티브 한글 IME의 실제 조합 이벤트 검증: 가드 구현·타입 검증까지 수행. 도구의 텍스트 입력은 실제 IME 조합을 재현하지 않음.
- 30분 연속 사용의 JS heap 추적, 정식 플레이 영상·청음 검수는 수행하지 않음. FPS 확인만으로 메모리 검증을 대체하지 않음.
- 원래 계획의 25~45문항 및 실패 후 추가 복습 3문항 규칙은 최신 '기본 암기와 같은 문항 수' 지시에 맞춰 변경됨.
- Phaser 청크는 약 1.69MB(압축 약 382KB)이며 전투 진입 때 지연 로드. Vite 크기 경고가 남음.
